# 頭痛ダイアリー（福岡天神頭痛と肺のクリニック）

患者さんがスマホで毎日の頭痛を記録し、受診のときに医師へ見せるためのウェブページです。
GitHub Pages でそのまま公開できます。

- **記録はその端末のブラウザ（localStorage）の中だけに保存**され、クリニックを含めどこにも送信されません。
- 外部のライブラリ・フォント・アクセス解析は使っていません。`index.html` 1ファイルで動きます。
- 日本語のみ。スマホ縦画面が基本で、パソコンでも使えます。本文16px以上、ボタン高さ44px以上。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 本体。設定（文言・選択肢・注意書き）・CSS・JavaScript をすべて含みます |
| `manifest.json` | ホーム画面に追加したときのアプリ名・色・アイコンの設定 |
| `sw.js` | 一度開いたあと、電波のない場所でも開けるようにする仕組み（Service Worker）。記録の送信はしません |
| `icon.svg` / `icon-180.png` / `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` | アイコン |
| `.nojekyll` | GitHub Pages にファイルをそのまま公開させるための印（中身は空） |
| `README.md` | この説明 |

## GitHub Pages で公開する手順

1. GitHub でこのリポジトリを開き、**Settings → Pages** を開く
2. **Build and deployment** の **Source** を「**Deploy from a branch**」にする
3. **Branch** を `main`、フォルダを「**/ (root)**」にして **Save**
4. 数分待つと `https://＜ユーザー名＞.github.io/headache-diary/` で公開されます（Settings → Pages にURLが表示されます）
5. 公開されたら、URLの末尾に `?demo` を付けて開き、見本データで各画面を確認してください（例：`https://＜ユーザー名＞.github.io/headache-diary/?demo`）

- GitHub Pages は自動で HTTPS になります（ホーム画面への追加や保存の保護に HTTPS が必要です）。
- `main` に変更を push すると、数分で公開内容が更新されます。
- 患者さんには公開URLをQRコードなどで案内してください。

## 文言・選択肢を直す場所

すべて `index.html` の先頭にある `const CONFIG = {` の中にまとめてあります。文字は `"` で囲み、行末の `,` を消さないでください。

| 場所（CONFIG 内） | 内容 |
|---|---|
| `clinic.name` | クリニック名（画面上部・印刷物・書き出しファイルに入ります） |
| `app.title` | ページ名（「頭痛ダイアリー」） |
| `app.exportReminderDays` ほか | 書き出しを促す間隔、カレンダーの週の始まりなど |
| `features.menstruationDefault` | 生理の欄を最初から表示するか（患者さん自身も「設定」画面で表示／非表示を切り替えられます） |
| `features.serviceWorker` | オフライン対応を使うか |
| `notices.*` | 注意書き（下の一覧を参照） |
| `options.painLevels` ほか | 痛みの強さ・支障・効き目・痛み方・症状・きっかけの選択肢。`label`（表示名）と `desc`（説明）は変えてよく、`id` / `value` / `cls` は保存データと結びついているので変えないでください |
| `text.*` | 画面のボタン名・見出し・案内文 |
| `text.help.*` | 「ホーム画面に追加する方法」ページの文章 |
| `demo.*` | `?demo` で表示する見本データの薬の名前・メモ |

このほか、`manifest.json` の `name` にもクリニック名が入っています（ホーム画面に追加したときのアプリ名）。クリニック名を変えるときは両方直してください。

| 場所（CONFIG 内） | 現在の文面 | 表示される場所 |
|---|---|---|

| `notices.privacy` | 記録はこのスマホ（この端末のブラウザ）の中だけに保存されます。クリニックを含め、どこにも送信されません。 | 設定・印刷物（上部の短い表示は `text.privacyBadge`） |
| `notices.preventiveMedNote` | 毎日決まって飲む予防の薬は、ここに書かなくてよいです。頭痛のときに飲んだ薬だけを記録してください。 | 記録画面の薬の欄 |

| `options.impactLevels[].label / sub` | なし／少しあった／大きかった（休んだ・寝込んだ） | 記録画面・表 |
| `options.effects[].label` | ○よく効いた／△少し効いた／×効かなかった | 記録画面・表 |
| `options.painTypes` | ズキズキ脈打つ／締めつけられる・重い／その他 | 記録画面（任意） |
| `options.symptoms` | 吐き気・吐いた／光がまぶしい／音がつらい／目の前がチカチカする（前兆）／めまい | 記録画面（任意） |
| `options.triggers` | 寝不足／寝すぎ／ストレス／天気・気圧／お酒／空腹／人混み | 記録画面（任意） |

| `text.help.*` | ホーム画面に追加する方法（iPhone・Android の手順と注意） | 「ホーム画面に追加する方法」ページ |
| `text.aboutBody` | （クリニック名） の患者さん向けの頭痛の記録表です。記録はこの端末の中だけに保存され、どこにも送信されません。 | 設定の「このページについて」 |

## 集計の決めかた

| 項目 | 数え方 |
|---|---|
| 記録した日数 | その月に何か1つでも記録がある日 |
| 頭痛があった日数 | 午前・午後・夜のどれかが「軽い」以上の日 |
| 強い頭痛の日数 | 午前・午後・夜のどれかが「強い」の日 |
| 生活に支障があった日数 | 支障が「少しあった」または「大きかった」の日（「うち大きかった日」も併記） |
| 頭痛薬を飲んだ日数 | 薬の記録が1件以上ある日（同じ日に何回飲んでも1日と数えます） |
| 薬の名前ごとの服用日数 | 薬の名前ごとに、飲んだ日の数（回数ではなく日数） |

服用日数には目安や助言を表示していません。必要になったら `notices.medicationNote` に文言を入れてください。

カレンダーには、その日いちばん強かった痛みを「色＋文字（－・軽・中・強）」で表示し、薬を飲んだ日に「薬」、生理の日に「生理」の印を付けます。空欄は記録なしです。

## 記録データについて

- 保存先はその端末のブラウザの `localStorage`（キー `ftz-headache-diary-v1`）です。サーバーには何も送りません。
- 保存の永続化を `navigator.storage.persist()` でブラウザに求めます（対応ブラウザのみ）。
- 「設定」から記録をファイル（JSON）に書き出し／読み込みできます。記録が7日以上あり、最後の書き出し（または最後のお知らせ）から30日たつと、記録画面でやさしく書き出しを促します。
- iPhone では、Safari で開いた記録とホーム画面のアイコンから開いた記録が別々に保存されます。移すときは「書き出し → 読み込み」を使います（アプリ内の案内ページにも書いてあります）。
- 記録を消すときは、画面の中で確認してから消します。
- 氏名・診察券番号は保存しません。印刷物に手書き用の空欄があります。

## 動作確認のしかた

- **見本データ**：URLの末尾に `?demo` を付けると、前月と今月の見本データで各画面を確認できます（見本は保存されず、入力しても消えます）。
- **スマホ幅**：パソコンのブラウザで開発者ツール（F12）のデバイスモードにし、iPhone などの幅で確認します。
- **印刷**：「医師に見せる」→「印刷する（A4 1枚）」。印刷画面で用紙サイズ A4・縦、「背景のグラフィック」をオンにすると色付きで出ます（白黒でも文字で区別できます）。

## 更新を反映するには

`index.html` を直して `main` に push すると、数分で公開内容が更新されます。
`sw.js` は「いつもネットワーク優先」で動くので、患者さんが次に開いたときに新しい内容が表示されます（電波がないときだけ前回の内容を表示）。

## 作りの前提・判断したこと

- 1日分の記録は日付ごとに1件。過去の日付も記録・修正・削除できます（未来の日付は選べません）。
- 入力は自動保存です（保存ボタンはありません）。「今日は頭痛なし」ボタンで午前・午後・夜と支障を1タップで「なし」にできます。
- 一度入れた薬の名前は候補として残り、次からワンタップで追加できます。候補は「設定」で整理できます。
- 痛み方・症状・きっかけ・メモは「くわしく記録する（任意）」にまとめ、ふだんは閉じています。
- 午前・午後・夜の区分と「なし／軽い／中くらい／強い」の4段階、生活への支障、服薬、生理の記録は、日本頭痛学会の頭痛ダイアリーに近い構成です。
